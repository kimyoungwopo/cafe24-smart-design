# 카페24 스킨 파일과 FTP 작업 흐름

카페24 스마트디자인은 관리자 편집기에서 코드를 수정할 수 있고, FTP 또는 파일 업로더를 통해 로컬 파일을 서버에 전송할 수도 있습니다. 실제 경로와 반영 방식은 쇼핑몰과 스킨 설정에 따라 확인해야 합니다. 운영 중인 대표 스킨에 바로 덮어쓰기 전에 테스트 스킨 또는 백업본으로 검증하세요.

1. 카페24 관리자에서 대상 쇼핑몰, PC/모바일 구분과 **스킨 번호**를 확인하고 해당 디자인을 백업합니다.
2. FTP 프로그램이나 카페24 파일 업로더에서 해당 스킨의 실제 폴더를 확인하고 필요한 기존 파일을 내려받습니다. FTP 접속 정보는 프로그램의 안전한 저장 기능이나 사용 중인 비밀 관리 방식으로 관리하고, 저장소나 AI 프롬프트에 넣지 않습니다.
3. 로컬에서 파일을 수정하고 변경 전후를 비교합니다. 폴더 구조, 문자 인코딩, 줄바꿈, 이미지·CSS·JS의 상대 경로 및 `module`, `{$...}`, 주석 지시문, action과 폼 변수를 확인합니다.
4. HTML 파일은 저장소 루트에서 다음 명령으로 추가 점검할 수 있습니다.

   ```bash
   node bin/cafe24-smart-design-check.mjs /path/to/local/skin
   ```

   결과의 미등록 항목은 오류 확정이 아닙니다. CSS·JS·이미지와 경로 유효성은 이 명령의 검증 범위가 아닙니다.
5. FTP로 **변경한 파일만** 올리기 전에 대상 경로와 백업을 다시 확인합니다. 현재 접속 환경에서 안전한 암호화 전송이 제공되는지 카페24의 접속 안내를 확인하고, 지원되는 방식으로 연결합니다. 관리자 설정이 연결된 일부 파일은 FTP 전송이 제한될 수 있으므로 오류를 우회하지 않습니다.
6. 카페24 테스트 스킨 또는 샘플 쇼핑몰에서 PC·모바일 preview를 확인합니다. 특히 상품 옵션, 로그인, 장바구니, 주문 등 영향을 받는 동작을 검증한 후 적용 여부를 결정합니다.

별도로 배포되는 Cafe24 Smart Design Guard 확장 프로그램은 **관리자 편집기 안의 현재 코드**를 읽어 변경 전후 계약 요소를 비교합니다. FTP 접속, 파일 동기화, 파일 업로드나 서버 상태 비교는 하지 않습니다. FTP로 업로드한 파일의 서버 반영 여부는 별도 클라이언트와 카페24 preview에서 확인하세요.
